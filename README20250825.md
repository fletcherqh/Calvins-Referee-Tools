# Patch: Output Log override (append + blank line, newest-on-top)

## Install
1) Copy `output-override.js` into your repo's `js/` folder.
2) In `test_main.html`, add this tag **near the end, after the existing output() is defined**, before `</body>`:
   ```html
   <script src="js/output-override.js"></script>
   ```

## Test
- Click `stats`, `reaction`, `loyalty` → each entry shows with a blank line between entries, newest at top.
